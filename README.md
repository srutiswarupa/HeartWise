## Project Overview

**HeartWise** is a beginner-friendly, end-to-end data analytics and machine learning project that analyses the UCI Cleveland Heart Disease dataset to predict the presence of heart disease. The project includes data cleaning, exploratory data analysis, classification modelling, evaluation, and an interactive Streamlit dashboard.

## Verified Results (from actual pipeline run)

### Dataset Summary
- Raw: 303 rows | Cleaned: 297 rows | Rows dropped: 6 (< 2%)
- Class balance: 160 no-disease (53.9%) / 137 disease (46.1%)
- Train/Test split: 237 train / 60 test (80/20 stratified)

### Model Performance on Test Set (60 samples)

| Model | Accuracy | Precision | Recall | F1 Score | ROC-AUC |
|-------|----------|-----------|--------|----------|---------|
| Logistic Regression | 83.33% | 84.62% | 78.57% | 81.48% | **94.87%** |
| **Random Forest** | **86.67%** | **88.46%** | **82.14%** | **85.19%** | 93.86% |

### Top 5 Predictive Features (Random Forest)
1. `cp` — Chest Pain Type (0.1500)
2. `oldpeak` — ST Depression (0.1226)
3. `thalach` — Max Heart Rate (0.1132)
4. `thal` — Thalassemia Type (0.1051)
5. `ca` — Vessels Coloured by Fluoroscopy (0.0949)

## Quickstart

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the analysis notebook
Open `SrutiSwarupa_HeartHealthAnalysis.ipynb` in Jupyter and run all cells:
```bash
jupyter notebook SrutiSwarupa_HeartHealthAnalysis.ipynb
```

### 3. Launch the interactive dashboard
```bash
streamlit run app.py
```
Opens at `http://localhost:8501`

### 4. Run the headless pipeline (optional)
```bash
python run_pipeline.py
```
